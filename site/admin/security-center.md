# 安全中心

管理后台「**安全中心**」里的每一项都可以设默认值，并**锁定**（锁定后员工改不了）。保存后几秒内下发到所有员工电脑生效，不用重装。

大多数项默认就是推荐值。下面按用途列出，「默认」是全新部署时的值。

## 文件与操作

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 工作区隔离 | 开 | 关掉后 AI 可以改工作区外的文件（危险命令仍然拦截） |
| 删除保护（回收站） | 开 | 删除进回收站，而不是永久删除 |
| 修改文件前自动备份 | 开 | 覆盖写之前留一份原文件，支持一键还原 |
| 备份容量上限 | 512 MB | |
| 批量删除确认阈值 | 20 | 一次删超过这个数量要额外确认 |
| 网络访问白名单 | 开 | 命令只能访问允许的地址 |
| 系统级工具 | 关 | 注册表、服务、计划任务、WMI |

## 任务质量

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 规划提醒 | 开 | 做了几步还没列计划时提醒 AI |
| 检查产出文件 | 开 | 检查生成的文件能不能打开、是不是空的 |
| 长任务模式 | 开 | 员工可以打开「长任务」 |
| 单次任务 token 上限 | 200 万 | 防止一个任务把额度烧光 |
| AI 用选项向员工提问 | 开 | 缺信息时弹选项卡片 |

## 能力开关（默认都关，按需给部分同事打开）

| 项 | 说明 |
| --- | --- |
| 浏览器操作 | AI 操作浏览器访问网页 |
| 后台命令 | 在后台跑开发服务器之类的长命令 |
| 开发者工具 | grep、批量修改、git、建 PR，见 [开发者工具](/guide/developer) |
| 子代理 | AI 开分身并行调研 |
| 允许主助手派遣专家 | 见 [专家](/guide/experts) |
| 命令行 / IDE 接入 | `flyknit -p` 和 IDE 插件，见 [命令行与 IDE](/guide/cli-and-ide) |
| 沙箱任务 | 本机 Docker 容器里无人值守写代码，见 [沙箱任务](/guide/sandbox)；另有能否上网、能否改 CI 配置、CPU、内存四项 |

## 命令拦截策略

默认已经拦截格式化磁盘、`diskpart`、改系统目录、关防火墙、关杀毒等危险命令，一般不用改。需要加自己的规则时，在管理后台的策略页添加正则，保存时会校验。

另外，后台「**工具规则**」可以按工具名和参数配置：直接拦截、每次都要确认、在结果后附提醒、把结果里的敏感内容打码。工具规则只会更严，不会放宽已有的安全检查。
