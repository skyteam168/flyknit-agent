# 安全中心

管理后台「**安全中心**」里的每一项都可以设默认值，并**锁定**（锁定后员工改不了）。保存后几秒内下发到所有员工电脑生效，不用重装。

## 三层设置

| 层 | 在哪里改 | 例子 |
| --- | --- | --- |
| 全厂 | 「安全中心」 | 所有电脑默认关闭开发者工具 |
| 部门 | 「部门 → 安全设置」 | 研发部打开开发者工具、命令行 / IDE 接入 |
| 单台电脑 | 「设备列表 → 详情 → 安全设置」 | 某台测试机单独放开沙箱任务 |

优先级：**单台电脑 > 部门 > 全厂**。部门和单台电脑只存「和上一层不一样」的项，其余跟随上一层，以后改全厂默认值时会自动跟着变。部门和单台电脑的安全设置只有超级管理员能改。设备详情里能看到这台电脑每一项最终生效的值来自哪一层。

大多数项默认就是推荐值。下面按用途列出，「默认」是全新部署时的值。

## 文件与操作

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 工作区隔离 | 开 | 关掉后 AI 可以改工作区外的文件（危险命令仍然拦截） |
| 删除保护（回收站） | 开 | 删除进回收站，而不是永久删除 |
| 修改文件前自动备份 | 开 | 覆盖写之前留一份原文件，支持一键还原 |
| 备份容量上限 | 512 MB | |
| 批量删除确认阈值 | 20 | 一次删超过这个数量要额外确认 |
| 网络访问白名单 | 开 | 命令只能访问允许的地址 |
| 系统级工具 | 关 | 注册表、服务、计划任务、WMI |

## 任务质量

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 规划提醒 | 开 | 做了几步还没列计划时提醒 AI |
| 检查产出文件 | 开 | 检查生成的文件能不能打开、是不是空的 |
| 长任务模式 | 开 | 员工可以打开「长任务」 |
| 单次任务 token 上限 | 200 万 | 防止一个任务把额度烧光 |
| 单个任务 token 上限（万） | 0（不限） | 一件事所有轮次加起来的上限。用完后长任务不再自动接着做，任务记成「任务额度用完」；员工再说话算新任务 |
| 看门狗 | 关 | 每分钟看一眼正在跑的任务：一直在动、却十几分钟没有新进展时，请便宜模型判断是不是卡住 / 跑偏，是就提醒 AI 并通知员工。命令执行中、等确认、暂停时不计时 |
| 看门狗：自动停下 | 关 | 提醒过、之后程序和模型仍认定没进展才停（和员工点停止一样）；模型判断失败时从不自动停 |
| 看门狗：多久没进展算可疑（分钟） | 10 | 5～60；长任务模式按 2 倍算 |
| 调度：归档追问、合并重复事件 | 关 | 钉钉 / 企业微信里同一个人有事在办时，追问交给原任务、问进度按记录回复；同样的事件 10 分钟内只处理一次。调度只做归档决定，不执行操作、不放宽权限 |
| 调度：一句话里的几件事分开做 | 关 | 问员工「要分开做吗？」，员工点了才拆；原对话汇总进度、合并确认（高危仍逐条点） |
| 分开做时同时做几件 | 1 | 1～3；大于 1 时写操作仍一次一个 |
| AI 用选项向员工提问 | 开 | 缺信息时弹选项卡片 |

## 命令拦截策略

默认已经拦截格式化磁盘、`diskpart`、改系统目录、关防火墙、关杀毒等危险命令，一般不用改。需要加自己的规则时，在管理后台的策略页添加正则，保存时会校验。

另外，后台「**工具规则**」可以按工具名和参数配置：直接拦截、每次都要确认、在结果后附提醒、把结果里的敏感内容打码。工具规则只会更严，不会放宽已有的安全检查。
