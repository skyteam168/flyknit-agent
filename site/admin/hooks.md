# 钩子

「工具规则」能按工具名和参数拦下、要求确认。但有些判断要问公司自己的系统：这个物料是不是冻结了、这笔金额有没有超过这个人的授权、这个文件是不是受控文档……这时用**钩子**。

钩子是公司内部的一个 HTTP 服务。AI 调用工具前、工具做完、一轮任务结束时，FlyknitBuddy 的服务端把这件事发给它。

## 它能做什么

| 事件 | 钩子能做的 |
| --- | --- |
| 调用工具前 | 回答「照旧」「必须员工确认」或「拦下」 |
| 工具做完 | 收到通知（工具、参数、成功与否、结果摘要），比如登记到自己的系统 |
| 任务结束 | 收到这一轮办事任务的结果摘要 |

钩子**只能收紧**：可以让本来自动执行的操作变成要确认、或者直接拦下；不能让本来要确认或被拦的操作自动执行。要求确认的操作，员工也不能选「以后自动允许」。

## 配置

后台「**运维 → 钩子**」，超级管理员才能新增、修改、测试和打开总开关：

| 项 | 说明 |
| --- | --- |
| 事件 | 调用工具前 / 工具做完 / 任务结束，可以多选 |
| 工具 | `*` 表示所有工具；例如 `mcp__erp__*, write_file`；「任务结束」不看这一项 |
| 参数匹配 | 可选，正则；参数里有这些内容时才调用，比如 `delete|amount` |
| 地址 | 钩子服务的地址 |
| 签名密钥 | 可选；填了每个请求都带签名，钩子服务据此确认请求来自 FlyknitBuddy |
| 超时 | AI 每次调用匹配的工具都要等它，建议 3 秒以内 |
| 没回应时 | 钩子超时或出错时：要员工确认（推荐）/ 拦下 / 照旧执行 |
| 使用范围 | 部门、个别电脑；都不选就是全公司 |

页面上的**总开关**默认关闭。地址和密钥只存在服务端，员工电脑拿不到。

点「**测试**」会发一条示例请求，看钩子能不能收到、回答对不对。页面下方能看到最近的调用记录（不保存参数原文）。

## 钩子服务怎么写

FlyknitBuddy 发 `POST` 请求，内容是 JSON：

```json
{
  "event": "pre_tool",
  "hook": "ERP 写操作审核",
  "device": {"machine_name": "PC-QC-01", "owner": "黎氏雪", "department": "质检部"},
  "tool": {"name": "mcp__erp__create_order", "arguments": {"material": "A01", "qty": 500}}
}
```

「调用工具前」要回答：

```json
{"decision": "ask", "reason": "建单数量超过 300，请主管确认"}
```

`decision` 只能是 `allow`（照旧）、`ask`（要确认）、`deny`（拦下）；其他回答一律按「要确认」处理。「工具做完」「任务结束」只需要返回 200。

设了签名密钥时，请求头 `X-Flyknit-Signature` 是 `sha256=` 加上「用密钥对请求体原文做 HMAC-SHA256」的十六进制结果。

## 插件里的钩子

插件包可以带 `hooks/http.json`，和技能、专家、连接器、工具规则一起按部门下发。插件装进来的钩子**默认关闭、没有签名密钥**，在「钩子」页会标出来自哪个插件；超级管理员确认地址可信、填好密钥后再打开。插件升级时如果钩子的地址或发送范围变了，会自动关掉，需要重新审核。

::: tip 发出去的内容
参数和结果里的密码、令牌、Cookie 会先打码，太长的内容会截断。「任务结束」只在办事模式下发送，普通对话和翻译不发。
:::
