# 编码模式（AI IDE）

给写程序的同事用：在 FlyknitBuddy 里打开项目代码，边看边让 AI 改，像用 Cursor 一样。

需要 IT 在安全中心打开「**开发者工具**」，并且办事对话选了工作区。满足条件时，标题栏会出现「**编码**」按钮，点一下进入，再点一下退出。

## 界面

| 位置 | 内容 |
| --- | --- |
| 左边 | **项目**（文件树）/ **技能** / **MCP 连接器** / **知识**（资料库） |
| 中间 | 代码编辑器（多标签、语法高亮、`Ctrl+S` 保存） |
| 右边 | **AI**：就是这个任务的对话，宽度可以拖 |
| 底部 | **终端** / **日志** / **Agent Trace**，高度可以拖，也可以收起 |

各栏的宽高、选中的标签会记住，下次打开照旧。进入编码模式时左侧主菜单自动收起，腾出地方。

## 项目文件树

- 最上面一行是工作区文件夹本身（比如 `EMPLOYEE-MANAGER`），点一下收起 / 展开整个项目。
- 右侧四个按钮：**新建文件**、**新建文件夹**、**刷新**、**全部收起**。
- 新建会放在选中的文件夹里（点过的文件夹，或者当前文件所在的文件夹；都没有就放在项目根）。输入名字回车确定，`Esc` 取消；新建的文件会直接在编辑器里打开。已经有同名的不会覆盖。
- AI 新建、删除、修改了文件，或者跑完命令、提交代码后，文件树会自动刷新，展开着的文件夹保持展开。
- `node_modules`、`dist` 这类依赖和编译输出文件夹显示成灰色。

只能在这个任务的工作区里新建、保存；二进制文件、特别大的文件、通过链接指到工作区外面的文件只能看不能改。

## AI 改代码时

- **跟着看**：AI 改了哪个文件，编辑器就打开哪个，左右对比标出改了哪里。不想自动打开就在标签栏右边的「**…**」里关掉「跟随 AI」。
- **保留 / 撤销 / 查看**（像 Cursor 的 Keep / Undo / Review）：AI 改的文件已经存进磁盘了。这一轮做完后，输入框上方会出现「N 个文件有改动 · 撤销 · 保留 · 查看」：
  - **保留**：认可这一轮的改动，不再提示（文件本来就已经保存好了）；
  - **撤销**：把这一轮 AI 改过的文件恢复成改之前的样子（会先问你；你在编辑器里还没保存的修改也会提醒）；
  - **查看**：打开这一轮的改动对比，可以只还原其中几个文件。
  - 编辑器里 AI 改过的文件上方也有「撤销此文件」「保留」，可以一个文件一个文件地决定。
- **你也在改**：你有没保存的修改时 AI 也改了同一个文件，不会悄悄覆盖，会让你选「用 AI 的」还是「用我的」。
- **对话里也能看**：AI 改文件的那一步下面直接显示改了哪几行（文件名、`+2 −1`，红色删、绿色加）。
- **输入框上方的汇总**：几个后台终端在跑（点开看终端）、最近一轮改了几个文件（点「查看」看对比、可以还原）。
- **恢复到这里**：自己发的每条消息旁边有「恢复到这里」，把这条消息之后 AI 改过的文件恢复成之前的样子。会先问你确认，对话记录不变。

## 选中代码交给 AI

在编辑器里选中一段代码，上方会出现：

- **添加到对话 `Ctrl+L`**：把文件名、行号和这段代码放进输入框，你再说要做什么。
- **快速修改 `Ctrl+K`**：直接在编辑器里写要求（比如「加上空值判断」），回车就交给 AI 只改这几行；`Esc` 取消。AI 正在忙别的时先放进输入框。

## AI 知道「这个项目」是哪个

工作区常常是一个装着很多项目的大文件夹（比如 `D:\AIWORK`）。编码模式里：

- 你当前打开的文件、光标在哪一行或选中了哪几行、还开着哪些文件，都会自动告诉 AI。你说「这个项目」「这个文件」「这里」，AI 就知道指的是哪个，不会去别的项目里找。
- AI 会从当前文件往上找项目的根文件夹（有 `package.json`、`.git` 之类的那一层）。项目比工作区小时，编辑器顶上提示「当前项目：xxx」，点「**设为这个任务的工作区**」可以把任务的工作区收窄到这个项目（命令、文件操作默认都在里面，更安全）。
- 第一次碰到一个项目时，AI 会先拿到一份项目概况：项目类型、`npm run` 脚本、主要依赖、目录结构，以及项目里的 `FLYKNIT.md`（输入 `/init` 可以生成）。
- 没开编码模式、工作区里又有好几个项目时，AI 会先列出候选项目问你，不会自己乱猜。

## 终端、日志、Agent Trace

**终端**像 VS Code：左边是画面，右边是列表。

- **你自己的 PowerShell**：点列表右上角的「+」新建，可以开多个（最多 6 个），起在任务的工作区。和你自己打开 PowerShell 一样，敲的内容不经过 AI，也不会记进日志。
- **AI 跑的命令**：列表里带 `∞` 的是 AI 跑的，包括一直在跑的后台命令（比如 `npm run dev`）。能看输出，还在跑的可以停；后台命令带颜色，需要时可以直接往里输入（比如按 `r` 让开发服务器重启）。AI 的命令照样先确认再执行。

**日志**是这个任务里每次工具调用的完整输出；**Agent Trace** 是这一轮 AI 每一步做了什么，点「完整链路」能看每一步的耗时和 token。

## 多个任务、历史

右边 AI 顶上有任务标签：

- **+**：在当前工作区新建一个任务，仍然留在编码模式。新任务的对话区会给几个常用的开头（分析项目结构、找 bug、补测试），点一下放进输入框。侧栏的「新建任务」和 `Ctrl+N` 在编码模式里也一样。
- **时钟按钮**：这个工作区以前的任务，可以搜索，点一下切过去。
- 关掉标签只是不显示，任务还在左侧列表和历史里。
- 新建、切换任务时，**编辑器里打开的文件不会关**：打开的文件属于这个工作区，不属于某个任务。

## 先出方案再动手（计划模式）

大一点的改动，建议先打开输入框下方的「**先出方案**」再说要做什么。这一轮 AI 只读代码、调研，不会改任何文件，最后给出一份方案。

方案好了，输入框上方会出现一张方案卡片：标题、几句说明、待办步骤，下面有三个按钮。

- **查看方案**：在编辑器里打开「方案.md」，可以直接改：删掉不要的步骤、加上你的要求、改措辞都行。改过的方案卡片上会标「已修改」。方案不会保存到项目里。
- **继续修改**：在输入框里说要怎么调整，AI 再出一版（仍然只调研、不改代码）。
- **执行**：退出计划模式，AI 开始按方案改代码。你改过方案的，AI 按你改后的这一版做。每一步该确认的照样会问你。

## 任务进度看板

AI 列了计划、或者开了子代理去做事时，输入框上方会出现一块看板，不用切回普通模式去看「计划」：

- **待办**：AI 列的每一步，正在做的高亮，做完的打勾划掉。点标题可以收起，收起后只显示「已完成 2 / 4 · 正在做的那一步」。
- **子代理 / 专家**：这一轮开出去的子代理，显示名字、正在做什么（比如「搜索代码」）和状态：进行中、等你确认、完成、没完成。点一下会跳到对话里它那张卡片。

## 对话太长了怎么办

一个任务里一直聊下去，每一步 AI 都要把前面的内容重新看一遍：越来越慢，也越来越费额度。

- 输入框右上方有「**上下文 N%**」：这个任务上一次用了模型多少「记忆空间」。到 75% 左右会自动把较早的内容整理成摘要。
- 用到 60% 以上，或者你打开了另一个项目的文件，输入框上方会建议新开任务：
  - **带上摘要新建**：新开一个任务，把当前任务整理成一份交接摘要（做过什么、改了哪些文件、还剩什么）。新任务的对话区会显示整理进度，整理好后直接显示摘要：点「**接着做**」马上开始，也可以在输入框里补充这次要做什么，摘要会跟你的第一句话一起交给 AI；不想带就点「不带了」。
  - **新建任务**：干净地开始。
  - **整理对话**：留在这个任务里，把较早的内容压成摘要。
- 建议：**一个功能、一个 bug 开一个任务**。效果最好，也最省额度。

## 打开的文件多了

- 标签放不下时可以横着滚（鼠标滚轮也行），切到的文件会自动滚到看得见的地方。
- 标签栏右边的「**…**」旁边会显示还有几个标签没显示出来，点开能直接选；里面还有「跟随 AI」「在 VS Code 中打开」「关闭其他」「关闭已保存」「全部关闭」。
- 有没保存的修改时，「…」左边会出现保存按钮（也可以按 `Ctrl+S`）。
- 在标签上点右键：关闭、关闭其他、关闭右侧、关闭已保存、全部关闭、复制路径；鼠标中键点标签直接关闭。
- 最多同时开 20 个文件，再多会自动关掉最早打开、没改过的。

## 在 VS Code 中打开

标签栏右边「**…**」里的「**在 VS Code 中打开**」，用你电脑上装的 VS Code 打开这个工作区；开着文件时直接跳到那个文件。没装 VS Code 会提示。

## 小提示

- 编辑器是 VS Code 同款的编辑器内核，但没有 VS Code 的插件；装插件、调试这类请用「在 VS Code 中打开」。
- 第一次进入编码模式会加载编辑器，稍等一两秒。
