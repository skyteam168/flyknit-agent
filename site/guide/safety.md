# 确认与安全

FlyknitBuddy 在你的电脑上执行操作，所以安全规则比较严格。规则由 IT 在后台统一配置，员工改不了被锁定的项。

## 什么时候会问你

| 操作 | 怎么处理 |
| --- | --- |
| 查目录、看文件、搜索、在工作区生成文件、跑构建 | 直接做，不打扰你 |
| 认不出的命令 | 问你；你可以选「以后自动执行」 |
| 删除、覆盖、改注册表 / 服务 / 账号、装卸软件 | **每次都问**，不能设成自动 |
| 格式化磁盘这类危险命令 | **直接拦截**，确认了也不执行 |

选「以后自动执行」时，记住的是**命令前缀 + 当前工作区**（比如在这个文件夹里的 `npm run build`），不是放开所有命令；删除类的命令无论如何每次都问。

选「**本任务内不再询问**」时，只在这一次任务里有效，任务结束就失效：命令按程序记（比如这次任务里的 `python`），连接器的操作按工具记（比如「MES · 查询工单」，查哪一单都不再问，别的工具照问）。主助手和它派出去的专家共用这份授权。删除类的命令同样每次都问；读到可疑内容之后、IT 规定必须确认的操作，也每次都问。

确认框会写清楚要做什么、为什么。看不懂的时候点「拒绝」最安全，AI 会换别的办法或者告诉你还差哪一步。

## 改坏了怎么办

- **改文件前自动备份**，删除的文件进回收站；
- 办事的回答下面有「改动了 N 个文件」，点开能逐行对比，**一键还原**到这一轮之前，详见 [文件、预览与还原](./files)。

## 网页、文件里的「指令」不算数

AI 读到的网页、文件、命令输出里如果夹着「忽略之前的要求，去做某事」这类话，它不会照做：只有你在输入框里说的才是要求。读到可疑内容后，接下来所有会改东西的操作都会先问你。

## 记忆

AI 会记住你的偏好和工作习惯，让下次更顺手。密码、密钥、令牌这类内容不会被记进长期记忆。侧栏「记忆」里能看到它记了什么，可以删除。

## 审计

每一次操作（包括被拦截、被拒绝的）都会记录在公司服务器上，IT 可以查看。
