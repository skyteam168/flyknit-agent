# 最近更新

升级到最新版后就能用。员工端会自动升级；命令行 `flyknit` 和员工端装在一起，一起升级。

## 2026 年 11 月

### 项目：把文件夹建成项目，随时回来接着做

左侧菜单多了「项目」：新建项目时写上名称、目标和说明，可以新建文件夹，也可以用已有的文件夹。项目里的任务，AI 第一次回答前会先看目标和说明。点开项目能看到里面的任务、新建任务，开了开发者工具的还能直接「在编码模式中打开」。首页「翻译」后面也多了「编码」入口。

→ [项目](/guide/projects)

### 编码模式：在 FlyknitBuddy 里像用 Cursor 一样写代码

开发者工具打开后，标题栏多了「编码」按钮：左边项目文件树 / 技能 / 连接器 / 知识，中间代码编辑器，右边 AI，底部终端、日志和 Agent Trace。

- AI 改了哪个文件就打开哪个，左右对比标出改动；选中代码按 `Ctrl+L` 加进对话、`Ctrl+K` 直接让 AI 改这几行。
- 终端像 VS Code：可以开自己的 PowerShell，也能看 AI 跑的后台命令（带颜色，能往里输入）。
- 文件树能新建文件、新建文件夹、刷新、全部收起；AI 改了文件会自动刷新。
- 你打开的是哪个项目、哪个文件、哪几行，AI 都知道；说「这个项目」不会再分析错。可以一键把任务的工作区收窄到当前项目。
- 右边能新建、切换任务，不会退出编码模式；「VS Code」按钮用你自己的 VS Code 打开项目。
- 对话里直接显示 AI 改了哪几行；自己的消息旁边有「恢复到这里」，一键撤回之后 AI 改过的文件。
- AI 改完一轮后可以「保留 / 撤销 / 查看」（像 Cursor 的 Keep / Undo / Review），也能在编辑器里一个文件一个文件地撤销或保留。
- 语言服务（IT 统一安装）：跳到定义、查找引用、补全、重命名、报错波浪线，支持 TS/JS/React、Vue、Python、Go、Java、C#；AI 也用它检查自己改的代码。
- 源代码管理：看改动、和上次提交对比、暂存、提交（AI 能帮写提交说明）、拉取 / 推送，不用再开别的工具。
- 全局搜索（`Ctrl+Shift+F`）：在整个工作区里找文字，支持区分大小写、全字、正则、包含 / 排除的文件，点结果直接跳过去。
- 子代理能按任务换模型；项目里可以用 `.flyknit/agents/*.md` 定义好常用的子代理（如代码审查员），AI 按名字派。
- 计划模式出了方案卡片：方案可以在编辑器里直接改，点「执行」AI 按你改后的方案做（像 Cursor 的 Plan / Build）。
- 输入框上方有任务进度看板：AI 的计划步骤和子代理的状态一眼就能看到。
- 新建、切换任务时打开的文件不再关掉；输入框上方显示上下文用了多少，对话太长或换了项目时建议新开任务，可以「带上摘要新建」。

→ [编码模式（AI IDE）](/guide/code-mode)

### 有敏感信息时不再中断任务

IT 打开数据脱敏后，要发给模型的内容里有身份证号、银行卡号、手机号、邮箱时，会先换成 `[邮箱_1]` 这样的占位符再发，回答里自动换回真实值；输入框上方会出现一条醒目的提示，写明换了哪几类、各几处，任务照常进行，不再出现「调用模型失败」。专家、子代理读到的内容也一样会提示。

### AI 浏览器：能输入网址、刷新，AI 操作时可以「接管」

浏览器窗口顶上有了后退、前进、刷新和可以输入的地址栏（只打开 http / https 网址）。AI 操作网页时页面上盖一层遮罩，免得误点打乱它；要自己操作就点「接管（Take Control）」，做完点「交还给 AI」，AI 接着做。

### 老电脑也能打开了

有的电脑上 WebView2 组件比较旧，以前装完一打开就报「界面加载失败」。新版会照常打开（窗口照样能拖动）；实在太旧时会直接说明原因和怎么处理，不再是一串看不懂的报错。IT 也可以让安装程序顺带把 WebView2 装好。→ [安装与登录](/guide/install)

### 命令行里也能整理对话、调权限

`flyknit` 对话里新增 `/compact`（整理对话，可以写要保留什么）、`/context`（上下文用量）、`/permission 只读|工作区`、`/think`（深度思考开关）、`/status`。打的字能用退格删，命令能用 Tab 补全。→ [终端对话](/guide/terminal#命令)

### 输入框里的斜杠命令

打 `/` 就能用 `/compact`（整理对话，可以说明要保留什么）、`/permission`、`/model`、`/plan`、`/context`、`/usage`、`/rewind`、`/fork`、`/status` 等命令，不用去找按钮，也不占额度。还有 `/review`（审查改动）、`/export`（导出对话）、`/doctor`（网络诊断）、`/feedback`、`/mcp`、`/long`、`/sandbox`。→ [使用方法](/guide/usage#斜杠命令)

### 视频、音频直接预览

AI 生成或找到的视频（mp4、webm、mov）和音频（mp3、wav、m4a 等），点「预览」就能在右侧直接播放、拖动进度条，几百 MB 的视频也不卡。编码放不了的会提示用系统播放器打开。→ [文件、预览与还原](/guide/files)

### 「关于」里能看到安装方式

设置 →「关于」会显示这台电脑是「安装版」还是「免安装版」。免安装版不会自动升级，旁边有「下载安装程序」，装一次即可（需要管理员密码，对话、记忆和设置都会保留）。

### 在命令行里直接对话

新开 cmd / PowerShell / Windows Terminal，进入文件夹输入 `flyknit`，就能像聊天窗口一样一句一句地交代：回答边生成边显示，每一步操作一行，需要确认的操作在命令行里问你（`y` 允许 / `a` 以后自动 / `n` 拒绝），`Ctrl+C` 停下当前这一轮。

`flyknit -c` 接着上次的对话，`flyknit --resume` 挑一个以前的对话接着聊。→ [终端对话](/guide/terminal)

### flyknit -p 不再「半天没反应」

在命令行里直接运行 `flyknit -p` 时，会边做边显示每一步在做什么，最后再输出结果；放在脚本里时输出不变。→ [命令行脚本与 CI](/guide/cli-and-ide)

### IDE 里更快、能找回以前的会话

- 关掉 VS Code 再打开，可以在插件的会话列表里找到以前的会话接着聊（命令行里也能 `/resume` 接着聊）。
- 回答和过程成段显示，不再一个字一个字地刷屏。
- 命令行和 IDE 默认不开深度思考，长任务明显更快；需要时加 `--think`。

→ [在 IDE 里用](/guide/ide)

### 回答里的 PR 链接显示成卡片

开着开发者工具时，回答里的 GitHub PR / Issue 地址显示成带图标的「#123」，鼠标停上去弹出卡片：状态（开放 / 草稿 / 已合并 / 已关闭）、标题、作者、改了多少行。→ [开发者工具与 PR](/guide/developer#聊天里的-pr-链接)

### 更省额度

- 长对话里，之前的内容可以被模型服务的缓存复用，每多聊一句要重新计费的部分少了很多。
- 读过的大文件、长命令输出会更早地精简，不会每一步都整段重发。
- 去掉了后台反复做的会话摘要。

日常使用不用做任何设置。

### 给管理员

- **按部门隔离**：技能、专家、连接器可以设「使用范围」，只给某些部门或某几台电脑用；范围外的电脑看不到、用不了。→ [管理后台一览](/admin/console#按部门隔离)
- **按部门 / 单台电脑设置安全中心**：比如只给研发部打开开发者工具、命令行 / IDE 接入；设备详情里能单独设置某一台。→ [安全中心](/admin/security-center)
- **找出不会自动升级的电脑**：设备列表新增「代理未安装」「免安装版」筛选，设备详情里能看到安装方式和 WebView2 版本。产品页下载可以勾选「只提供安装程序」，不再让员工下到免安装版。→ [装到员工电脑](/admin/rollout#找出不会自动升级的电脑)
- **运维代理自动升级**：安全中心新增「运维代理自动升级」（默认关），打开后代理跟着员工端一起升级，新版本跑不起来会自动换回；老代理可以用「安装软件」推一次安装程序（静默参数 `/S /deferred`）完成升级。设备列表新增「代理版本旧」筛选。老电脑的命令行 `flyknit` 也会自动加进 PATH。→ [装到员工电脑](/admin/rollout#运维代理升级)
- **WebView2 离线安装包**：打包时加 `-WithWebView2Runtime`，安装程序在 WebView2 没装或太旧的电脑上顺带装好。→ [装到员工电脑](/admin/rollout#webview2-运行时)
- **用量按用途看**：仪表盘新增「按用途」，分开看正常对话和压缩上下文、任务复盘、整理记忆、生成标题这些后台调用各用了多少，以及模型服务的缓存命中率。→ [管理后台一览](/admin/console)
