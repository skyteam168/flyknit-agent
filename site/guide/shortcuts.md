# 翻译、截图与快捷键

## 划词翻译

在**任何程序**里选中一段文字，按 `Ctrl + Alt + T`，鼠标旁边弹出译文：

- 默认译成界面语言；原文已经是界面语言时，自动译成中文或越南语；
- 可以改原文重译、复制，或转到主窗口继续。

## 截图提问

按 `Ctrl + Alt + S`（或右键悬浮球「截图提问」），框选屏幕上的一块，作为附件开一个新对话直接问。

## 资源管理器右键菜单

- 在文件上右键：「发给 FlyknitBuddy 提问 / 总结 / 翻译」，多选的几个文件进同一个对话；
- 在文件夹上右键：「在这里用 FlyknitBuddy 办事」。

Windows 11 在「显示更多选项」里。

## 常用快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Space` | 打开 / 收起主窗口 |
| `Ctrl + Alt + T` | 划词翻译 |
| `Ctrl + Alt + S` | 截图提问 |
| `Ctrl + N` | 新建任务 |
| `Ctrl + ;` | 顺便问一句 |
| `Enter` / `Shift + Enter` | 发送 / 换行 |

所有快捷键都能在「设置 → 快捷键」里改，冲突时会提示被谁占用。
