# 安装与登录

## 系统要求

- Windows 10（1809 及以上）或 Windows 11；
- Windows 10 如果提示缺少 WebView2，请 IT 装一次 WebView2 Runtime（免费）；
- 能访问公司的 FlyknitBuddy 服务器（由 IT 告诉你地址，一般装好就配置好了）。

## 安装

一般由 IT 统一安装：双击安装程序，输入一次管理员密码，装好后桌面和开始菜单都有 FlyknitBuddy。

也可以在公司的 FlyknitBuddy 产品主页下载安装包，具体以 IT 的通知为准。

::: tip 「Windows 已保护你的电脑」
第一次运行安装程序时 Windows 可能提示「未知发布者」，点 **更多信息 → 仍要运行**。
:::

## 登录

第一次打开会弹出登录窗口，勾选同意《用户协议》《隐私政策》后：

- **加了公司域的电脑**：显示当前的域账号，直接点「授权登录」；
- **没加域的电脑**：点「使用账号密码登录」，输入 Windows 账号和开机密码。密码只由本机 Windows 校验，不保存、不上传。

登录后桌面右下角出现悬浮球，左下角显示你的名字和部门。

## 升级

新版本由 IT 在后台发布，电脑会在后台自动下载。看到「重启升级」时点一下，或者下次关掉程序时会自动换好。

## 卸载

「设置 → 应用 → 应用和功能」里找到 FlyknitBuddy 卸载。你的对话记录和记忆留在 `%APPDATA%\Flyknit`，卸载不会删除。
