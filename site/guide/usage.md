# 三种模式与工作区

## 打开窗口

- 点桌面上的**悬浮球**，或按 `Ctrl + Alt + Space`；
- 悬浮球可以拖到任何位置，**把文件拖到球上**就直接发给 AI；
- 右键悬浮球有更多功能：对话浮窗、划词翻译、截图提问等。

## 三种模式

输入框左下角切换：

| 模式 | 适合 | 会不会动你的电脑 |
| --- | --- | --- |
| **办事** | 整理文件、汇总表格、写文档、执行命令 | 会，按[确认规则](./safety)来 |
| **对话** | 问问题、写东西、出主意 | 不会 |
| **翻译** | 文字或整份文件翻译 | 不会 |

## 工作区

办事模式下，输入框下方能选**工作区**（一个文件夹）。

- AI 生成的文件都放在工作区里；
- 默认权限「工作区内修改」下，AI 只能改工作区里面的东西，改外面的要问你；
- 在资源管理器里右键文件夹「在这里用 FlyknitBuddy 办事」，可以直接以这个文件夹为工作区开新任务。

## 权限

| 权限 | 说明 |
| --- | --- |
| 仅可查看 | 只能看、只能查，不能改任何东西 |
| 工作区内修改（默认） | 只能在工作区里新建、修改文件；命令按规则确认 |
| 完全权限 | 可以改工作区外的文件，普通命令不再确认；危险命令仍然拦截。只对当前这个任务有效，IT 也可以关掉这一档 |

## 好用的小功能

- **增强提示词**：输入框里点 ✨，把随手写的一句话改写得更清楚，不满意点 ↺ 恢复；
- **斜杠命令和快捷指令**：输入框里打 `/` 列出全部命令，方向键选、回车执行（见下面的表）；IT 和你自己加的快捷指令也在里面，比如 `/周报`；
- **先出方案**：点「先出方案」，AI 只调研、写出打算怎么做，你看过再点「按方案执行」；
- **运行中插话**：AI 还在做的时候可以继续打字补充要求，不用等它做完；
- **顺便问一句**：`Ctrl + ;` 问一个和当前任务有关的小问题，不打断正在跑的任务；
- **从这里分叉**：任意一条回答下点分叉按钮，另开一个对话试别的方向，原对话不受影响。

## 斜杠命令

在输入框里打 `/` 就会列出来。这些命令在电脑上直接办，**不发给 AI、不占额度**（`/compact`、`/init` 除外），和点界面上对应的按钮效果完全一样，IT 的限制照样生效。

| 命令 | 作用 |
| --- | --- |
| `/help` | 列出全部命令 |
| `/compact 要保留的内容` | 马上整理对话，比如 `/compact 保留报价和交期`；后面不写就照常整理 |
| `/permission 仅可查看 \| 工作区内修改 \| 完全权限` | 调这个对话的权限；选「完全权限」照样会先弹确认 |
| `/model 模型名` | 换模型；只打 `/model` 列出能选的，`/model auto` 交给系统选 |
| `/plan` | 打开 / 关闭「先出方案」 |
| `/new`（`/clear`） | 开一个新对话 |
| `/context` | 看上下文用了多少 |
| `/usage` | 看今天的额度 |
| `/rewind` | 打开上一轮改动的文件，看过再决定还不还原 |
| `/fork` | 从最新的回答分出一个新对话 |
| `/memory` | 管理记忆 |
| `/status` | 这个对话正在用的模式、模型、权限、工作区、额度一览 |
| `/btw 问题` | 顺便问一句，不打断任务 |
| `/init` | 开了开发者工具时：生成项目说明 FLYKNIT.md |

快捷指令和这些命令重名时，以命令为准。
