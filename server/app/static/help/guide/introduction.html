介绍 ​

FlyknitBuddy 是装在办公电脑上的 AI 助手：桌面上一个悬浮球，点开就是聊天窗口。你用平常说话的方式告诉它要做什么，它在你的电脑上把事情办了。

能做什么 ​

办事读写文件、整理文件夹、汇总 Excel、写 Word / PPT、执行命令、打开软件
对话问问题、写东西、出主意，不碰你的电脑
翻译中文、越南语、英语等多种语言互译，整份文件也能翻，保留格式
专家IT 为各业务配好的 AI 专家，懂流程、懂术语
定时任务每天、每周自动执行的固定工作
命令行 / IDE在 cmd、PowerShell 里输入 flyknit 直接对话；也能接进 VS Code 等开发工具（IT 开启后）

界面语言支持简体中文、Tiếng Việt、English。

它是怎么工作的 ​

你的电脑                                   公司服务器
┌────────────────────────────┐            ┌──────────────────────────┐
│ FlyknitBuddy                │            │ FlyknitBuddy 服务端       │
│  · 悬浮球 / 聊天窗口         │  ◄──────►  │  · 转发给 AI 模型          │
│  · 在本机执行操作并请你确认   │            │  · IT 的安全设置与额度      │
│  · 对话记录、记忆存在本机     │            │  · 技能库、专家、审计记录   │
└────────────────────────────┘            └──────────────────────────┘
  • 操作都在你的电脑上执行，需要确认的会先弹框问你；
  • 你的电脑不直接连 AI 模型，所有请求都经过公司服务器，模型的密钥只存在服务器上；
  • 对话记录、记忆存在你自己的电脑里（%APPDATA%\Flyknit），换 Windows 账号看不到。
