沙箱任务 ​

想让 AI 在不打扰你的情况下长时间写代码、跑测试？打开沙箱任务：它在你电脑上的一次性 Docker 容器里干活，中途不弹确认，做完推到一个新分支并建 PR。

前提 ​

  • IT 在安全中心打开了「开发者工具」和「沙箱任务」；
  • 电脑装了 Docker Desktop（WSL 里的 Docker 只要认 docker 命令也行）；
  • 工作区是一个 GitHub 仓库。

怎么用 ​

  1. 办事输入框下方点「沙箱」打开；
  2. 第一次发话时会准备容器（复制仓库进去），右侧仓库面板显示进度和任务分支 flyknit/…；
  3. 之后读写文件、执行命令、装依赖、跑测试都在容器里，不弹确认，也不会改你本机的文件；
  4. AI 做完用 create_pull_request 把任务分支推上去建 PR，然后按盯 PR 的规则跟进 CI。

能离开容器的只有一条路 ​

规则说明
只推任务分支只能推 flyknit/ 开头的分支，不能推默认分支，不能强推
CI 配置默认不许改（IT 可以打开）
改动数量一次超过 2000 个文件不自动推
钩子仓库里的 git 钩子不会在你的电脑上执行
凭证推送用你电脑上的 git 登录，令牌不进容器

读到疑似「提示词注入」的内容后，推送这一步会改为先问你。

关闭沙箱 ​

再点一次「沙箱」，或仓库面板里「结束沙箱」。会删除容器，没推送出去的改动会丢失，已经建好的 PR 不受影响。
