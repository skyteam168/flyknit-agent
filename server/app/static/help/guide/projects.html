项目 ​

把一个文件夹建成项目，写上目标和说明，之后随时回来接着做。左侧菜单里的「项目」就是入口。

项目是什么 ​

  • 一个项目 = 一个文件夹 + 名称 + 目标 + 补充说明。
  • 项目里的任务：工作区在这个文件夹里（或它的子文件夹里）的任务，都算这个项目的。
  • 项目里的任务第一次发消息时，AI 会先看到项目的目标和说明，不用每次重新交代。

新建项目 ​

左侧「项目」右边的「+」，或者项目页右上角的「新建项目」：

  • 名称：比如「订单系统」。
  • 您想做什么？（可选）：项目目标，比如「把下单接口的 p95 延迟降到 200 毫秒以内」。
  • 放在哪：
    • 新建一个文件夹，放在某个工作区里（下面会显示会新建的完整路径）；
    • 或者用已有的文件夹（点「选择文件夹并新建」再选）。
  • 补充说明（可选）：项目约定、背景、要注意的地方，比如「用 pnpm；接口在 api/ 下；不要改数据库结构」。

目标和说明里不要写密码、令牌。

在项目里接着做 ​

点开一个项目：

  • 项目里的任务：最近的在前，点一下接着做。
  • 新建任务：在项目文件夹里开一个新任务。
  • 在编码模式中打开（开发者工具打开后才有）：接着这个项目最近的办事任务，直接进编码模式；没有任务就新开一个。
  • 目标、说明、名称都可以直接改，点「保存」。

「从项目列表移除」只是不在这里显示，文件夹和里面的任务都不会删除。

项目页右上角可以搜索项目、切换排序（最近打开 / 名称）。
