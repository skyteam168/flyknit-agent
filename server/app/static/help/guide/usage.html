三种模式与工作区 ​

打开窗口 ​

  • 点桌面上的悬浮球，或按 Ctrl + Alt + Space；
  • 悬浮球可以拖到任何位置，把文件拖到球上就直接发给 AI；
  • 右键悬浮球有更多功能：对话浮窗、划词翻译、截图提问等。

三种模式 ​

输入框左下角切换：

模式适合会不会动你的电脑
办事整理文件、汇总表格、写文档、执行命令会，按确认规则来
对话问问题、写东西、出主意不会
翻译文字或整份文件翻译不会

工作区 ​

办事模式下，输入框下方能选工作区（一个文件夹）。

  • AI 生成的文件都放在工作区里；
  • 默认权限「工作区内修改」下，AI 只能改工作区里面的东西，改外面的要问你；
  • 在资源管理器里右键文件夹「在这里用 FlyknitBuddy 办事」，可以直接以这个文件夹为工作区开新任务。

权限 ​

权限说明
仅可查看只能看、只能查，不能改任何东西
工作区内修改（默认）只能在工作区里新建、修改文件；命令按规则确认
完全权限可以改工作区外的文件，普通命令不再确认；危险命令仍然拦截。只对当前这个任务有效，IT 也可以关掉这一档

好用的小功能 ​

  • 增强提示词：输入框里点 ✨，把随手写的一句话改写得更清楚，不满意点 ↺ 恢复；
  • 斜杠命令和快捷指令：输入框里打 / 列出全部命令，方向键选、回车执行（见下面的表）；IT 和你自己加的快捷指令也在里面，比如 /周报；
  • 先出方案：点「先出方案」，AI 只调研、写出打算怎么做，你看过再点「按方案执行」；
  • 运行中插话：AI 还在做的时候可以继续打字补充要求，不用等它做完；
  • 顺便问一句：Ctrl + ; 问一个和当前任务有关的小问题，不打断正在跑的任务；
  • 从这里分叉：任意一条回答下点分叉按钮，另开一个对话试别的方向，原对话不受影响。

斜杠命令 ​

在输入框里打 / 就会列出来。这些命令在电脑上直接办，不发给 AI、不占额度（/compact、/init 除外），和点界面上对应的按钮效果完全一样，IT 的限制照样生效。

命令作用
/help列出全部命令
/compact 要保留的内容马上整理对话，比如 /compact 保留报价和交期；后面不写就照常整理
/permission 仅可查看 | 工作区内修改 | 完全权限调这个对话的权限；选「完全权限」照样会先弹确认
/model 模型名换模型；只打 /model 列出能选的，/model auto 交给系统选
/plan打开 / 关闭「先出方案」
/new（/clear）开一个新对话
/context看上下文用了多少
/usage看今天的额度
/rewind打开上一轮改动的文件，看过再决定还不还原
/fork从最新的回答分出一个新对话
/memory管理记忆
/status这个对话正在用的模式、模型、权限、工作区、额度一览
/btw 问题顺便问一句，不打断任务
/init开了开发者工具时：生成项目说明 FLYKNIT.md
/review 重点看什么开了开发者工具时：审查还没提交的改动，AI 只看不改，列出问题清单
/mcp打开连接器页：看连接状态、重新连接
/export把这个对话导出成 Markdown，放进这个对话的工作区（不会覆盖已有文件）
/doctor打开网络诊断
/feedback（/bug）意见反馈，自动带上这个对话的标题和编号
/long打开 / 关闭长任务模式
/sandbox开了沙箱任务时：打开 / 关闭沙箱（关的时候照样先确认）

快捷指令和这些命令重名时，以命令为准。
