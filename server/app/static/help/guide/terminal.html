终端对话 ​

不打开聊天窗口，直接在 cmd、PowerShell 或 Windows Terminal 里和 FlyknitBuddy 一句一句地聊，让它在当前文件夹里读文件、跑命令、改代码。体验类似 Codex CLI、Claude Code。

用的是这台电脑上 FlyknitBuddy 的登录，权限、确认、额度、审计和聊天窗口完全一样。

开始之前 ​

要求怎么确认
IT 打开了「命令行 / IDE 接入」没开时运行 flyknit 会提示「IT 没有开启命令行 / IDE 接入」，找 IT 在安全中心打开
这台电脑登录过 FlyknitBuddy打开桌面端登录一次即可，命令行用同一个登录
装的是新版输入 flyknit --help，第一行是「flyknit　在命令行里和 FlyknitBuddy 对话」就是新版

flyknit.exe 和 FlyknitBuddy 装在一起（默认 C:\Program Files\FlyknitBuddy），安装时已经加进 PATH，新开一个命令行窗口就能用。

推荐用 Windows Terminal

Win11 自带，开始菜单搜「终端」。颜色、中文、表格显示效果最好。cmd 和 PowerShell 也都能用。

第一次对话 ​

1. 打开命令行，进入要处理的文件夹

bat
cd /d D:\工作\日报
flyknit
powershell
cd D:\工作\日报
flyknit

cd /d 在 cmd 里可以连盘符一起切换。进入的文件夹就是这次对话的工作区：AI 默认只在这里面读写，生成的文件也放在这里。

2. 看到欢迎画面后直接打字，回车发送

终端窗口不够宽（不到约 100 列）时，大字会换成一行小字；把输出重定向到文件时只输出文字信息。

3. 看它干活

  ▸ 列出目录 .
    ✓ 共 31 个文件
  ▸ 读取 10-01.xlsx
    ✓ Sheet1：42 行
  … 思考中
  ▸ 执行 python merge.py
  ⚠ 需要确认：执行 python merge.py
    理由：用脚本把 31 个文件合并成一张表
    [y] 允许一次  [a] 以后自动  [n] 拒绝 > y
    已允许这一次
    ✓ 已生成 10月汇总.xlsx
汇总好了，放在 D:\工作\日报\10月汇总.xlsx，共 31 天、1302 行……
· 3 次工具 · 18.4k tokens · 42.1 秒

>
看到的意思
▸ …开始一步操作（读文件、跑命令、改文件……）
✓ / ✗这一步成功 / 失败，后面是结果的第一行
… 思考中在等 AI 回复，第一个字出来就会消失
· 3 次工具 · 18.4k tokens · 42.1 秒这一轮结束：用了几次工具、多少 token、多久；没做完时会写原因

4. 接着说下一句，它记得前面聊过的内容。说完了输入 /exit 退出。

需要确认的操作 ​

和聊天窗口里的确认卡片一样，只是改成在命令行里问：

输入效果
y允许这一次
a允许，并且以后同类操作自动执行（和 FlyknitBuddy 里的「以后自动」是同一套规则，可以在 FlyknitBuddy「设置 → 自动执行规则」里撤销）
n 或直接回车拒绝，AI 会换别的办法或者问你
  • 删除、覆盖、改系统设置这类高危操作只有 y / n，输入 a 会再问一次。
  • 查目录、看文件这类只读操作不问，直接做。
  • 命令行里没有「完全权限」，最多是「工作区内修改」。

命令 ​

在 > 后面输入：

命令作用
/help显示命令说明
/new开一个新对话（当前的已经保存）
/resume列出这个文件夹里以前的对话，输入序号打开接着聊
/resume 2直接打开列表里的第 2 个
/plan看当前的任务计划
/usage这个对话用了多少 token（和聊天窗口共用今日额度）
/compact马上整理对话：较早的压成摘要，省 token；后面可以写要重点保留的，如 /compact 保留报价和交期
/context上下文用了多少、系统提示 / 工具 / 对话各占多少
/permission 只读调权限：只读 或 工作区；不带参数看当前是哪一档。命令行没有完全权限
/think打开 / 关闭深度思考（也可以写 /think 开、/think 关）；打开后会显示思考过程
/status版本、会话、工作区、权限、开发者工具、深度思考一览
/clear清屏
/exit退出

打 / 和命令的头几个字母，按 Tab 自动补全（比如 /pl + Tab → /plan、/th + Tab → /think）；对得上的有好几个时（比如 /p 既可能是 /plan 也可能是 /permission），再按一次 Tab 把它们列出来。

输入时的按键 ​

按键作用
退格删掉最后一个字
Esc清空这一行
Tab补全命令
↑ / ↓翻之前输过的话

输入多行 ​

  • 行尾加 \ 回车，接着写下一行。
  • 粘贴大段文字：先单独输入一行 """ 回车，粘贴，再输入一行 """ 回车。
> """
… 帮我把下面这段需求整理成任务清单：
… 1. 每天 8 点汇总各车间日报
… 2. 缺勤超过 3 人的车间标红
… """

停下和退出 ​

操作效果
任务进行中按 Ctrl+C只停下这一轮（已经开始的操作照常收尾），回到 > 继续聊
空闲时按 Ctrl+C提示「再按一次退出」；两秒内再按一次才退出
输入 /exit退出

对话每一轮结束都会自动保存，直接关掉窗口也不会丢。

接着以前的对话 ​

bat
flyknit -c              :: 接着这个文件夹里最近的一次对话
flyknit --resume        :: 列出以前的对话，选一个接着聊

打开后会显示上次最后一问一答，提醒你聊到哪了。

命令行和 IDE 里的对话存在同一个地方（这台电脑上，最多 50 个、保留 30 天，不上传），在 VS Code 里聊了一半，可以回到命令行里接着聊，反过来也一样。

常用参数 ​

bat
flyknit "看看这个项目是做什么的"        :: 带着第一句话进入
flyknit -w D:\repo                     :: 指定工作区，不用先 cd
flyknit --permission readonly          :: 只读：只能看，不能改
flyknit --think                        :: 让 AI 每一步先深度思考（更慢、更费额度）

深度思考默认关，不跟聊天窗口里的「深度思考」开关走：命令行里的任务常常要十几、几十步，每步都先想一大段会慢很多。真遇到难题再加 --think。

用法举例 ​

想做的事可以这样说
整理文件夹「把这里的文件按月份分到不同文件夹，先列出计划给我看」
汇总表格「把所有 xlsx 的第一个工作表合成一张，按日期排序」
看懂一个项目「这个项目是做什么的？目录结构和主要模块讲一下」
改代码「把 utils.py 里的两个 TODO 修掉，改完跑一下测试」
查问题「运行 npm test，失败的话找出原因并修好」

改代码、用 git、建 PR 需要 IT 打开「开发者工具」，见 开发者工具与 PR。

一次性任务（flyknit -p） ​

只想跑一次、拿到结果就结束（比如放进脚本或计划任务）时用 -p：

bat
flyknit -p "把 docs 目录里的 md 文件列出来" --format text

在命令行里直接运行时会边做边显示进度，最后输出结果。-p 没有人可以问，需要确认的操作默认一律拒绝，结束时会列出被拒绝的操作；要执行脚本、访问网络这类需要你点头的事，去掉 -p 用对话模式。详见 命令行脚本与 CI。

遇到问题 ​

提示「'flyknit' 不是内部或外部命令」

PATH 只对新开的窗口生效，关掉重开一个命令行。还不行就用完整路径：

bat
"C:\Program Files\FlyknitBuddy\flyknit.exe"

输入 flyknit 只显示帮助，不进入对话

用的是旧版本。可以先看看实际用的是哪一个：

bat
where flyknit

列出多个时，排在第一个的会被使用。升级 FlyknitBuddy 到最新版，或者用完整路径运行新版。

flyknit -p 半天没反应

旧版 -p 要等整个任务做完才输出。升级到新版会边做边显示进度；需要来回确认的事情改用 flyknit 对话。

打的字删不掉、Tab 不补全

升级到最新版。旧版输入行交给系统处理，第一个字退格删不掉，也没有 Tab 补全。

中文是乱码、颜色是一堆奇怪的符号

升级到最新版。新版对话时会自动切换到 UTF-8，并在老的 cmd 窗口里打开颜色支持。还有问题就换 Windows Terminal。

提示「还没登录 FlyknitBuddy」

打开桌面端 FlyknitBuddy 登录一次。登录过期了也一样，重新登录即可。

提示「IT 没有开启命令行 / IDE 接入」

找 IT 在管理后台「安全中心」（或你所在部门的安全设置）里打开。

提示今天的额度用完了

命令行和聊天窗口共用每天的额度，第二天自动恢复，急用找 IT 调整。
