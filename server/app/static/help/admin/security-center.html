安全中心 ​

管理后台「安全中心」里的每一项都可以设默认值，并锁定（锁定后员工改不了）。保存后几秒内下发到所有员工电脑生效，不用重装。

三层设置 ​

层在哪里改例子
全厂「安全中心」所有电脑默认关闭开发者工具
部门「部门 → 安全设置」研发部打开开发者工具、命令行 / IDE 接入
单台电脑「设备列表 → 详情 → 安全设置」某台测试机单独放开沙箱任务

优先级：单台电脑 > 部门 > 全厂。部门和单台电脑只存「和上一层不一样」的项，其余跟随上一层，以后改全厂默认值时会自动跟着变。部门和单台电脑的安全设置只有超级管理员能改。设备详情里能看到这台电脑每一项最终生效的值来自哪一层。

大多数项默认就是推荐值。下面按用途列出，「默认」是全新部署时的值。

文件与操作 ​

项默认说明
工作区隔离开关掉后 AI 可以改工作区外的文件（危险命令仍然拦截）
删除保护（回收站）开删除进回收站，而不是永久删除
修改文件前自动备份开覆盖写之前留一份原文件，支持一键还原
备份容量上限512 MB
批量删除确认阈值20一次删超过这个数量要额外确认
网络访问白名单开命令只能访问允许的地址
系统级工具关注册表、服务、计划任务、WMI

任务质量 ​

项默认说明
规划提醒开做了几步还没列计划时提醒 AI
检查产出文件开检查生成的文件能不能打开、是不是空的
长任务模式开员工可以打开「长任务」
单次任务 token 上限200 万防止一个任务把额度烧光
AI 用选项向员工提问开缺信息时弹选项卡片

能力开关（默认都关，按需给部分同事打开） ​

项说明
浏览器操作AI 操作浏览器访问网页
后台命令在后台跑开发服务器之类的长命令
开发者工具grep、批量修改、git、建 PR，见 开发者工具
子代理AI 开分身并行调研
允许主助手派遣专家见 专家
命令行 / IDE 接入flyknit -p 和 IDE 插件，见 命令行与 IDE
沙箱任务本机 Docker 容器里无人值守写代码，见 沙箱任务；另有能否上网、能否改 CI 配置、CPU、内存四项

记忆与个性化 ​

项默认说明
学习偏好 / 常用信息 / 经验教训 / 历史任务 / 自动沉淀技能开可以分别关掉
允许玩笑类语气、自定义语气和名字开
允许锁屏运行、保持屏幕常亮开
允许截图提问开
员工可以查看上下文用量的详细拆分开
任务完成通知、通知提示音开 / 关员工可以自己改

命令拦截策略 ​

默认已经拦截格式化磁盘、diskpart、改系统目录、关防火墙、关杀毒等危险命令，一般不用改。需要加自己的规则时，在管理后台的策略页添加正则，保存时会校验。

另外，后台「工具规则」可以按工具名和参数配置：直接拦截、每次都要确认、在结果后附提醒、把结果里的敏感内容打码。工具规则只会更严，不会放宽已有的安全检查。
