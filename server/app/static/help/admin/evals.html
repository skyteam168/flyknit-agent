回归评测 ​

改了专家的说明、技能、模型或提示词之后，以前答得好的问题现在还答得好吗？回归评测把一组固定的问题存下来，每次改完跑一遍、自动打分、和上一次对比，变差的题会标出来。

建题集 ​

后台「运维 → 回归评测」，新建题集：

项说明
谁来回答选一位专家，或者「普通办事助手」
执行机一台常开的专用电脑（可以和无人值守任务用同一台），要用到的连接器、技能装好登录好；选了专家的话，这位专家要下发到这台电脑
权限上限仅可查看 / 工作区内修改。评测一律只预演，不会真的改任何东西
及格分有评分标准的题，模型打分不低于这个才算通过（默认 60）

每道题写一个问题（像员工平时那样问），再至少填一种判分方式：

判分方式例子
回答必须包含12480（一车间上周的真实产量）
回答不能包含不知道、无法查询
正则|\s*车间\s*|（回答里要有车间表格）
评分标准「要提到产量、达成率、不良率三项，不能编造数字」——由模型按这句话打 0-100 分

跑一次、看结果 ​

点「跑一次」，可以写一句这次改了什么（比如「专家说明改到 v3」）。题目派到执行机上，做完自动打分，页面上能看到：

  • 通过几题、平均几分；
  • 比上次退步的题（上次通过、这次没过）标成红色；
  • 每题的检查结果、模型打分和理由、AI 的回答。

同一个题集上一次还没跑完时不能再跑。执行机一直没上线，题目过期后算没通过。

题目编号

和上一次对比是按题目编号对的。编号可以自己填（比如 yield-weekly）；改了编号，这一题就和以前的记录对不上了。

不会影响员工

评测只预演，需要确认的操作一律拒绝；评测对话不会写进 AI 的长期记忆，结果只在后台看。
