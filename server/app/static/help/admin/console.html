管理后台一览 ​

浏览器打开服务端的 /admin，用管理员账号登录。

页面作用
仪表盘设备、用量、拦截记录概览；用量可以按模型（含缓存命中率）、按用途（正常对话、压缩上下文、任务复盘、整理记忆、生成标题、看门狗、调度等后台调用）分开看
设备列表所有电脑的在线和资产信息；正在跑几个任务，有任务在跑却十几分钟没心跳的标「失联（有任务在跑）」；编辑使用者、部门（从部门清单里选）、备注；停用某台；向某台电脑远程下发指令；详情里看这台电脑能用的技能 / 专家 / 连接器，单独设置安全中心的项
部门部门清单（改名会同步到设备和使用范围；还在用的部门不能删）；每个部门单独设置安全中心的项
指令中心远程指令的下发、进度、结果；指令模板

账号与权限 ​

后台账号是具名的，可以分别授权：

  • 能不能查看聊天内容（查看会记入访问记录）；
  • 能不能远程下发指令；
  • 超级管理员才能管理账号和部分全局开关。

共享的管理员令牌只用于命令行脚本，不能查看聊天内容、不能下发指令。

按部门隔离 ​

技能、专家、MCP 连接器都有「使用范围」：选哪些部门、另外哪几台电脑能用。

  • 不选 = 全公司都能用（已有的条目升级后就是这样，行为不变）；
  • 范围由服务端执行：范围外的电脑在员工端看不到，按名字直接下载技能包、使用或派遣专家也会被拒绝；连接器里 IT 预填的公共账号只下发给范围内的电脑；
  • 收回范围（或电脑换了部门）后，员工端几秒内同步：之前从技能库装的技能被删掉、连接器断开、专家从列表消失；
  • 插件带来的技能 / 专家 / 连接器，要同时在插件的下发部门和条目自己的范围里。

例如：考勤技能、考勤专家、考勤连接器都把范围设成「行政部」，只有行政部的电脑能用。
