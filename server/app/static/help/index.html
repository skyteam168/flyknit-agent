FlyknitBuddyAI 办公助手

装在工厂办公电脑上，说出要做的事，剩下的交给它。办事、对话、翻译，中文、越南语、英语都行。

管理员部署
🛠️

办事：替你操作电脑

读写文件、整理文件夹、汇总 Excel、写 Word 和 PPT、执行命令。每一步都看得见，改动前自动备份，删除进回收站。

🛡️

危险操作先问你

查目录、看文件直接做；删除、覆盖、改系统设置每次都要你点头。危险命令直接拦截，IT 统一管控。

🌐

中越英翻译

整段、整份文件都能翻，保留格式。任何程序里选中文字按 Ctrl+Alt+T，就地弹出译文。

👥

专家与技能

IT 为生产、质检、行政等业务配好的 AI 专家，懂流程、懂术语；技能和连接器让它会用公司的系统。

⏱️

长任务与定时任务

要做很久的事中途关机也不丢，回来接着做；每天、每周自动跑的报表汇总交给它。

💻

给写程序的同事

开发者工具、仓库与 PR、Docker 沙箱里无人值守干活，还能在命令行和 IDE 里直接调用。

⌨️

在终端里对话

打开 cmd 或 PowerShell 输入 flyknit，像 Codex CLI 一样一句一句地交代，确认、停止、接着上次聊都在命令行里完成。
