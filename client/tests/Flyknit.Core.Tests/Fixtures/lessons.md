# 经验与教训

AI 每次完成任务后的复盘，下次做同类任务时会参考。

## 成功经验
- 生成 PPT 先套用模板母版，再逐页填内容，最后导出预览图检查版式（2026-10-01）
- 质检周报先按车间汇总再画折线图，阅读最清楚（2026-10-02）
- 调用设备管家接口前先用公钥加密登录拿 token，再批量拉取台账（2026-10-03）
- 批量处理 Excel 先用 pandas 读成 DataFrame 再统一清洗（2026-10-03）
- 用 Outlook COM 接口发邮件前先确认可发信账户（2026-10-04）
- 整理文件先列目录再批量移动，避免漏文件（2026-10-04）

## 失败教训
- PowerShell 里跑 python -c 内联脚本容易被转义和引号坑，应改为写脚本文件再执行（2026-10-01）
- 在 PowerShell 里用 python -c 写含正则引号的脚本会被解析器破坏，应先写成 .py 文件再执行（2026-10-02）
- 在 PowerShell 里用 python -c 写含中文的代码会因引号/编码报错，应改为写入 .py 文件再执行（2026-10-03）
- PowerShell 中 python -c 多行脚本引号转义易出错，应写成 .py 文件再执行（2026-10-05）
- 读取 .xls 旧格式要先另存为 .xlsx 再读取，否则会乱码（2026-10-01）
- 不要假设接口返回结构，先打印完整响应确认字段路径（如 token 在 data.list 而非 data）（2026-10-03）
- 登录加密的是整个 JSON 串而不是明文密码，容易搞错（2026-10-03）
- python-pptx 不支持直接复制幻灯片，需要从模板版式新建（2026-10-02）
- 写文件前确认目标目录存在，否则会报找不到路径（2026-10-04）
