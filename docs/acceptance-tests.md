# 验收测试清单（PR #93 ～ #99）

覆盖 2026-11-07 晚到 2026-11-08 合并的功能。每一条都写了**怎么测**和**达到什么效果才算通过**。

## 给执行者（FlyknitBuddy）的规则

1. **用「办事」模式**，工作区选一个专门的测试文件夹（下文叫 `T:\fbtest`，可换成任何空文件夹），不要在真实业务目录里测。
2. 每条用例按「步骤」执行，对照「通过标准」**逐条**判断。只有全部标准都满足才记「通过」；拿不到证据的记「未验证」，不要猜。
3. 标 🤖 的你自己执行并取证（命令输出、文件内容、截图路径）；标 👤 的需要员工或 IT 在界面上看或点，你先说清楚要看什么，等对方告诉你结果再记录。
4. 需要员工确认的操作弹框时，**不要**替员工决定；用例里写了该点哪个按钮。
5. **不要把令牌、密码写进对话、文件或命令行参数**。需要管理接口时，用员工事先放进环境变量的值（`$env:FLYKNIT_ADMIN_SESSION`），命令里只引用变量名。
6. 结果写进 `T:\fbtest\验收结果.md`，用文末的表格格式：编号、结果（通过 / 失败 / 未验证）、证据、备注。失败的写清楚实际看到了什么。

## C. 连接器（MCP）稳定性（PR #93 阶段 2）

前置：至少连上一个连接器（最好一个本机进程类 stdio、一个在线类 http）。

**C1 停止时通知对方取消** 👤
- 步骤：让它调用一个耗时的连接器工具，中途点「停止」。
- 通过标准：任务立即停下；连接器日志（见 C3）里有 `notifications/cancelled`。

**C2 本机进程崩溃自动重启** 👤
- 步骤：连接器连上并运行超过 30 秒后，在任务管理器里结束它的进程。
- 通过标准：连接器面板几秒内显示重新连接并恢复「已连接」；10 分钟内连续杀 4 次，第 4 次后不再自动重启并显示原因。

**C3 每个连接器一份打码日志** 🤖
- 步骤：打开 `%APPDATA%\Flyknit\logs\mcp\` 下对应连接器的 `.log`。
- 通过标准：有连接、断开、调用的记录；**没有**明文的 API Key、Token、Cookie、密码（只出现打码后的形式）；不包含工具调用的参数和返回内容。

**C4 健康检查与延迟** 👤
- 通过标准：连接器面板显示延迟数值；断网 1 分钟后状态变为断开，恢复网络后自动重连。

**C5 工具返回图片** 👤（需要能返回图片的连接器，比如截图类）
- 通过标准：对话里显示返回的图片；场景模型支持识图时，下一句问「图里写了什么」能答出来。

**N2 设备部门只能从清单选** 👤
- 通过标准：「设备列表 → 编辑」里部门是下拉框，只能选清单里的部门。

**N3 技能按部门隔离** 👤 + 🤖
- 步骤：技能库里给一个技能设「使用范围：行政部」。分别在行政部电脑和研发部电脑上打开员工端「技能」页。
- 通过标准：
  - 行政部电脑能看到并安装；研发部电脑**看不到**；
  - 研发部电脑之前从技能库装过这个技能的，几秒内（最晚 10 分钟）自动删掉；
  - 研发部员工自己从别处装的技能**不受影响**；
  - 「设备列表 → 详情 → 这台电脑能用的」和员工端看到的一致。

**N4 专家按部门隔离** 👤
- 步骤：给一位专家设范围「行政部」。
- 通过标准：只有行政部电脑的「专家」列表里有它；研发部电脑的主助手也派遣不到它（派遣记录里没有研发部电脑的这位专家）。

**N5 连接器按部门隔离** 👤
- 步骤：给一个 IT 预填了公共账号的连接器设范围「行政部」。
- 通过标准：只有行政部电脑能看到、能连接；研发部电脑原来连着的会自动断开，列表里看不到。

**N6 单独放开某台电脑** 👤
- 步骤：在 N3 的技能范围里「另外再给这些电脑」加上一台研发部电脑。
- 通过标准：只有这一台研发部电脑能看到，其他研发部电脑看不到。

**N7 范围留空 = 全公司** 👤
- 通过标准：没设范围的技能 / 专家 / 连接器，所有部门都能看到（和升级前一样）。

**N8 部门安全设置** 👤
- 步骤：「部门 → 研发部 → 安全设置」把「开发者工具」设为开，保存。
- 通过标准：研发部电脑几秒内办事模式出现 grep / git 工具，行政部电脑没有；设备详情里这一项标注来自「部门」。

**N9 单台电脑优先于部门** 👤
- 步骤：在一台研发部电脑的「设备列表 → 详情 → 安全设置」里把「开发者工具」设为关。
- 通过标准：这台电脑没有开发者工具，其他研发部电脑仍然有；设备详情标注来自「这台电脑」；点「恢复跟随部门 / 全厂」后又回到部门的设置。

**N10 只有超级管理员能改** 👤
- 通过标准：用普通管理员账号打开部门 / 设备的安全设置，只能看、不能保存。
